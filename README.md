# letsc

A lightweight browser-based single-player Pac-Man clone.

## Run locally

Because this project is just static files, you can open `index.html` directly in a browser or serve the folder with a small local server:

```bash
cd <project-directory>
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Controls

- Arrow keys / WASD: move Pac-Man
- Enter or the on-screen button: start or restart
- Mute button: toggle sound effects
